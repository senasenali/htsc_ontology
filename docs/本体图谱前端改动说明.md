# 本体图谱前端展示逻辑修改说明

## 改动 1：OT 节点精简 — 不展示属性

ObjectTypeNode 在图谱中**只显示名称**，不展示属性、ID、图标等信息。
属性详情在用户点击 OT 后的侧边栏（DetailPanel）中展示。

- 节点宽度：160px
- 节点高度：40px
- 字号：12px
- 四个方向保留 Handle（top/bottom/left/right）

## 改动 2：边（Edge）默认隐藏，选中后动态展示

- **默认状态**：不渲染任何边（edges 状态为空数组）
- **选中某个 OT 时**：从所有 LinkType 边中筛选出 `source === 选中ID || target === 选中ID` 的边，动态注入到 edges 状态中并设置 opacity 0.85 显示
- **取消选中时**：清空 edges 回到空数组

这样避免了 1000+ 条边同时渲染形成"毛线球"的问题。
