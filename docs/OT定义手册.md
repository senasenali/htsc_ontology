# 本体论（OT）分类定义手册

> 本文档定义半导体本体论中每一类 OT（Ontology Type）的核心定义、归属判断标准、边界案例及典型示例。用于在知识图谱构建中确保分类一致性。

---

## 1. 技术路线（Technology Route）

**描述：** 半导体行业实现计算、存储、通信等能力所采用的技术，以及其演进体系。

> 技术路线关注 **"技术是什么，以及如何演进"**，而非"哪个公司生产"或"最终卖什么产品"。

**下属对象类型包括：**

- 技术世代层
- 技术能力层
- 工业应用层

**不包括：**
- ✗ 公司
- ✗ 产品型号
- ✗ 财务指标
- ✗ 市场应用领域

---

## 2. 三层次体系详解

### 2.1 技术世代层（Technology Generation Layer）

**描述：** 行业公认的技术代际演进节点。代表行业在某个方向上的阶段性技术水平。

> 回答的是："目前发展到第几代了？"

**纳入原则：**

- 子OT的实例之间存在明显时间演进关系；
- 行业通常使用“第几代”进行描述；
- 上一代与下一代之间存在继承和升级关系。

**子OT的实例通常具备：**
- 时间顺序
- 技术继承关系
- 明显代际升级

**例如：**
- 28nm → 14nm → 7nm → 5nm → 3nm
- DDR4 → DDR5 → DDR6
- Pascal → Volta → Ampere → Hopper → Blackwell

**不包括：**
- ✗ 具体实现技术
- ✗ 产品型号
- ✗ 企业品牌

---

#### 2.1.1 制程节点世代（Process Node Generation）

**描述：** 逻辑芯片制造工艺的代际划分体系。实例为行业认可的制程节点，通常以 nm 或品牌节点命名。

**实例：**
- 28nm / 14nm / 7nm / 5nm / 3nm / 2nm

**判断标准：**
- ✓ 行业用于衡量逻辑工艺先进性的节点
- ✓ 具有明确代际关系

**不包括（重要边界）：**
- ✗ N3E —— 属于制造工艺平台
- ✗ N2P —— 属于制造工艺平台
- ✗ Intel 18A —— 属于制造工艺平台

---

#### 2.1.2 指令集架构世代（ISA Generation）

**描述：** 软件与硬件交互的指令规范体系。

> 回答的是：CPU 能够理解什么语言？

**实例：**
- x86
- ARM
- RISC-V
- MIPS

**判断标准：**
- ✓ 定义指令规范
- ✓ 定义寄存器体系
- ✓ 被多个 CPU 设计采用

**不包括：**
- ✗ Zen —— 属于微架构
- ✗ Neoverse —— 属于微架构
- ✗ Cortex —— 属于微架构

---

#### 2.1.3 CPU 微架构世代

**描述：** 在特定 ISA 下实现 CPU 设计的代际方案。

> 回答的是：如何实现 ISA？

**实例：**
- Zen / Zen 2 / Zen 3 / Zen 4 / Zen 5
- Cortex-A76 / Cortex-X4

**判断标准：**
- ✓ 基于某个 ISA
- ✓ 具有明确代际升级关系
- ✓ 定义流水线、缓存、执行单元等设计

**不包括：**
- ✗ x86 —— 属于 ISA
- ✗ ARM —— 属于 ISA

---

#### 2.1.4 GPU 架构世代

**描述：** GPU 计算架构的代际演进体系。

**实例：**
- Kepler / Pascal / Volta / Ampere / Hopper / Blackwell / Rubin

**判断标准：**
- ✓ 定义计算核心组织方式
- ✓ 定义内存体系结构
- ✓ 存在明确代际关系

**不包括：**
- ✗ H100 —— 属于产品
- ✗ B200 —— 属于产品

---

#### 2.1.5 DRAM 世代

**描述：** DRAM 标准的代际演进体系。

**实例：**
- DDR3 / DDR4 / DDR5 / DDR6
- LPDDR4 / LPDDR5 / LPDDR6

**判断标准：**
- ✓ JEDEC 定义的内存代际标准
- ✓ 具备性能升级关系

**不包括：**
- ✗ HBM —— 应归属于 HBM 世代

---

#### 2.1.6 HBM 世代

**描述：** 高带宽存储器的代际演进体系。

**实例：**
- HBM / HBM2 / HBM2E / HBM3 / HBM3E / HBM4 / HBM5

**判断标准：**
- ✓ 采用 3D 堆叠
- ✓ 面向高带宽场景
- ✓ 存在代际升级

**不包括：**
- ✗ DDR5 —— 属于 DRAM 世代
- ✗ LPDDR5 —— 属于 DRAM 世代

---

### 2.2 技术能力层（Technology Capability Layer）

**描述：** 支撑技术世代持续演进的核心能力。

> 回答的是："为什么能够进入下一代？"

**特点：**
- 能力层通常不会按时间顺序排列
- 作为底层技术长期存在

**实例通常表现为：**
- 制造能力
- 封装能力
- 互联能力
- 光学能力
- 架构能力

**例如：**
- FinFET / GAA / EUV / CoWoS / NVLink / CPO

**不包括：**
- ✗ 产品
- ✗ 工艺平台名称
- ✗ 商业解决方案

---

#### 2.2.1 晶体管架构（Transistor Architecture）

> **⚠ 这是整个图谱最重要的 OT 之一。**

**描述：** 晶体管结构设计方案。

> 回答的是：如何继续缩小晶体管？

**实例：**
- Planar / FinFET / GAA / RibbonFET / CFET

**判断标准：**
- ✓ 改变晶体管结构
- ✓ 提升缩放能力
- ✓ 被多个制程节点采用

**不包括：**
- ✗ 3nm —— 属于制程节点
- ✗ 2nm —— 属于制程节点

---

#### 2.2.2 光刻技术（Lithography）

**描述：** 芯片图形转移能力。

**实例：**
- g-line / i-line / KrF / ArF / ArFi / EUV / High-NA EUV

**判断标准：**
- ✓ 属于曝光技术
- ✓ 决定制程分辨率能力

**不包括：**
- ✗ 光刻机型号
- ✗ NXE:3600D

> 设备不是技术。

---

#### 2.2.3 先进封装技术（Advanced Packaging）

**描述：** 多个芯片协同集成的核心封装能力。

**实例：**
- 2.5D 封装 / 3D 封装 / Chiplet / Hybrid Bonding / TSV

**判断标准：**
- ✓ 属于封装能力
- ✓ 可被多个封装方案复用

**不包括：**
- ✗ CoWoS-S —— 属于工业应用层（封装方案）
- ✗ Foveros —— 属于工业应用层（封装方案）

---

#### 2.2.4 互联架构（Interconnect Architecture）

**描述：** 芯片、封装或系统内部的数据交换组织方式。

**实例：**
- Mesh / Ring / Crossbar / NVLink Fabric / Scale-Up Fabric

**判断标准：**
- ✓ 定义数据流动方式
- ✓ 定义拓扑结构

**不包括：**
- ✗ PCIe —— 属于互联标准
- ✗ UCIe —— 属于互联标准

---

#### 2.2.5 互联标准（Interconnect Standard）

**描述：** 产业统一遵循的数据通信协议标准。

**实例：**
- PCIe / CXL / UCIe / HBI

**判断标准：**
- ✓ 存在标准组织
- ✓ 存在规范文档
- ✓ 可跨企业采用

**不包括：**
- ✗ NVLink —— NVLink 属于专有互联架构

---

#### 2.2.6 光互连技术（Optical Interconnect）

**描述：** 利用光信号替代电信号完成数据传输的技术体系。

**实例：**
- 硅光子 / CPO / Optical IO / On-chip Photonics

**判断标准：**
- ✓ 使用光而非电作为传输介质
- ✓ 面向高带宽低功耗互联

**不包括：**
- ✗ 光模块产品
- ✗ 交换机产品

---

#### 2.2.7 封装基板技术（Substrate Technology）

**描述：** 先进封装中承载芯片与互联结构的基板技术。

**实例：**
- ABF 基板 / 玻璃基板 / TGV / BT 基板

**判断标准：**
- ✓ 属于封装载体技术
- ✓ 决定布线密度与尺寸能力

**不包括：**
- ✗ CoWoS —— 属于封装方案
- ✗ InFO —— 属于封装方案

---

#### 2.2.8 特色工艺平台（Specialty Process Platform）

> 未来会经常用到。

**描述：** 面向特定应用场景的专用制造工艺体系。其目标不是追求最先进节点，而是追求特定性能。

**实例：**
- BCD / LDMOS / SiGe / RF SOI / HV CMOS

**判断标准：**
- ✓ 面向特定应用优化
- ✓ 可跨多个制程节点存在

**不包括：**
- ✗ 3nm —— 属于先进逻辑制程节点
- ✗ 5nm —— 属于先进逻辑制程节点

---

### 2.3 工业应用层（Industrial Application Layer）

**描述：** 企业将技术能力工程化后形成的实际交付平台或解决方案。

> 回答的是："产业界具体如何使用这些技术？"

**实例通常具有：**
- 企业归属
- 商业品牌
- 产品化交付

**例如：**
- N3E / A14 / CoWoS-S / InFO / Foveros

**不包括：**
- ✗ 基础技术原理
- ✗ 技术标准
- ✗ 技术世代名称

---

#### 2.3.1 晶圆制造平台（Wafer Process Platform）

> ⚠ 原名"制造工艺"，建议改用此名称以消除歧义。

**描述：** 晶圆厂向客户提供的具体制造平台。平台通常是 **制程节点 + 晶体管架构 + 光刻技术 + 设计规则** 的工程化组合。

**实例：**
- N3E / N2P / A14 / Intel 18A

**判断标准：**
- ✓ 可以直接被客户 Tape-out
- ✓ 具有商业化平台名称

**不包括：**
- ✗ 3nm —— 属于制程节点世代（底层技术）
- ✗ FinFET —— 属于晶体管架构（底层技术）
- ✗ EUV —— 属于光刻技术（底层技术）

---

#### 2.3.2 封装方案（Packaging Solution）

**描述：** 企业向客户提供的商业化先进封装解决方案。

**实例：**
- CoWoS-S / CoWoS-L / InFO / SoIC / Foveros

**判断标准：**
- ✓ 可直接被客户采用
- ✓ 属于产品化封装平台

**不包括：**
- ✗ TSV —— 属于先进封装技术（底层技术）
- ✗ Hybrid Bonding —— 属于先进封装技术（底层技术）

## 3. 边界决策速查表

| 易混淆对 | 甲 → 归入 | 乙 → 归入 | 判断依据 |
|----------|-----------|-----------|----------|
| 3nm vs N3E | 3nm → **制程节点世代** | N3E → **晶圆制造平台** | 前者是代际标签，后者是商业化平台 |
| N3E vs FinFET | N3E → **晶圆制造平台** | FinFET → **晶体管架构** | 前者是工程组合交付，后者是底层能力 |
| x86 vs Zen | x86 → **ISA 世代** | Zen → **CPU 微架构** | 前者是指令规范，后者是具体设计实现 |
| ARM vs Cortex | ARM → **ISA 世代** | Cortex → **CPU 微架构** | 同上 |
| H100 vs Hopper | H100 → **产品（不入图谱）** | Hopper → **GPU 架构世代** | 前者是产品型号，后者是架构代际 |
| CoWoS-S vs TSV | CoWoS-S → **封装方案** | TSV → **先进封装技术** | 前者是商业方案，后者是底层能力 |
| PCIe vs NVLink | PCIe → **互联标准** | NVLink → **互联架构** | 前者有标准组织，后者是专有架构 |
| DDR5 vs HBM3 | DDR5 → **DRAM 世代** | HBM3 → **HBM 世代** | 应用场景与架构不同 |
| EUV vs NXE:3600D | EUV → **光刻技术** | NXE:3600D → **设备产品（不入图谱）** | 技术 vs 设备型号 |

---

## 4. 分类流程

判断一个实体应归入哪个 OT 时，按以下顺序决策：

```
1. 这是产品型号吗？         → 不入图谱（如 H100, B200, NXE:3600D）
2. 这是公司或品牌名吗？      → 不入图谱
3. 描述的是"第几代"？        → 技术世代层
   ├─ 逻辑工艺代际 → 制程节点世代
   ├─ 指令规范     → ISA 世代
   ├─ CPU 设计实现 → CPU 微架构世代
   ├─ GPU 架构     → GPU 架构世代
   ├─ 内存代际     → DRAM 世代 / HBM 世代
4. 描述的是"凭什么"？        → 技术能力层
   ├─ 晶体管结构   → 晶体管架构
   ├─ 曝光技术     → 光刻技术
   ├─ 封装能力     → 先进封装技术
   ├─ 数据交换方式 → 互联架构 / 互联标准
   ├─ 光传输       → 光互连技术
   ├─ 封装载体     → 封装基板技术
   ├─ 专用工艺     → 特色工艺平台
5. 描述的是"怎么卖/怎么用"？ → 工业应用层
   ├─ 晶圆厂交付   → 晶圆制造平台
   ├─ 封装厂交付   → 封装方案
```
