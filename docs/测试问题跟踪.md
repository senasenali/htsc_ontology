### 3. 智能对话返回"系统存在技术问题"，无法查询实例数据

| 字段 | 内容 |
|------|------|
| **问题描述** | 智能对话可以连接并返回概念信息，但提问"电芯有哪些实例"时回答"系统目前存在技术问题，暂时无法返回实例数据"，仅返回对象类型定义和关联关系，缺少实例列表 |
| **排查过程** | ① 直接调用 MCP Client API 测试 `curl -X POST http://localhost:8001/api/chat` → ② 查看 MCP Client 日志，发现 `MCP connection lost, reconnecting...` 出现在 DeepSeek API 调用之后 → ③ 查看 MCP Server 日志，确认出现 `AsyncRequestTimeoutException` → ④ 确认默认 SSE async request timeout 过短，连接在 LLM 思考期间断开 |
| **根本原因** | Tomcat SSE（Server-Sent Events）async request 默认超时时间约 10 秒。DeepSeek API 调用耗时超过该阈值，导致 SSE 连接断裂。当 Agent 的 LLM 调用完成后，尝试通过已断开的 SSE 连接调用 `queryInstanceGraph` 工具时失败，实例数据无法返回。 |
| **解决方案** | 在 `backend/mcp-server/src/main/resources/application.yml` 中添加 `spring.mvc.async.request-timeout: 120000`，将 SSE 超时延长至 2 分钟。重启 MCP Server 和 MCP Client 后生效。 |
| **状态** | ✅ 已解决 |
